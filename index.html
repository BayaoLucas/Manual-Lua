CAPÍTULO 01

O que é Lua?

Conhecendo a linguagem que combina simplicidade e eficiência.

🌙 Conhecendo Lua

Lua é uma linguagem de programação criada em 1993, na Pontifícia Universidade Católica do Rio de Janeiro (PUC-Rio), por Roberto Ierusalimschy, Luiz Henrique de Figueiredo e Waldemar Celes.

Ela foi desenvolvida para ser leve, eficiente e fácil de incorporar em outros programas. Sua sintaxe simples permite que iniciantes aprendam programação sem lidar com uma estrutura excessivamente complicada.

Onde Lua é utilizada?

⚔️

World of Warcraft

O famoso MMORPG utiliza Lua para personalizar sua interface e desenvolver AddOns, que permitem adicionar funcionalidades, ferramentas e modificações à experiência dos jogadores.


🎮

Jogos

Utilizada em jogos e motores de desenvolvimento para criar comportamentos e sistemas.

⚙️

Automação

Permite criar scripts que automatizam tarefas e processos.

💻

Aplicações

Pode ser incorporada em softwares desenvolvidos em outras linguagens.

🌐

Sistemas

É utilizada em sistemas embarcados e diferentes ferramentas tecnológicas.

✦

CAPÍTULO 02

Instalando Lua

Prepare seu ambiente para começar a programar.

Como instalar?

Para executar programas em Lua, você precisa instalar o interpretador da linguagem no seu computador.

  1. Entre no site oficial da linguagem Lua.
  2. Acesse a seção de downloads.
  3. Baixe a versão compatível com seu sistema operacional.
  4. Instale e configure o interpretador.
  5. Abra o terminal e digite lua -v para verificar a instalação.
Acessar site oficial da Lua ↗

Seu primeiro arquivo

Crie um arquivo com o nome primeiro.lua e escreva:

print("Olá, universo!")

print("Estou aprendendo Lua!")

Depois, execute o arquivo pelo terminal:

lua primeiro.lua

CAPÍTULO 03

Sintaxe básica

Entenda como escrever instruções em Lua.

O comando print()

O comando print() é utilizado para exibir informações na tela. Ele é muito útil para testar programas e visualizar resultados. 

print("Olá, mundo!")
print(100)
print(10 + 5)
RESULTADO Olá, mundo!
100
15

Comentários

Comentários são textos que o interpretador ignora. Eles servem para explicar o funcionamento do código. 

-- Este é um comentário de uma linha

--[[
    Este é um comentário
    de várias linhas
]]
⭐

Lua diferencia letras maiúsculas de minúsculas. Por exemplo, print e Print não são o mesmo comando.

CAPÍTULO 04

Variáveis em Lua

Armazenando informações durante a execução.

O que são variáveis?

Variáveis são espaços utilizados para armazenar informações que podem ser acessadas e modificadas durante a execução de um programa. 

local nome = "Marina"
local idade = 20
local altura = 1.65

print(nome)
print(idade)
print(altura)

Variáveis locais e globais

A palavra-chave local cria uma variável local, limitada ao seu escopo. Já uma atribuição sem local pode criar ou modificar uma variável global, caso não exista uma variável local com aquele nome. 

local pontuacao = 100

mensagem = "Olá!"

print(pontuacao)
print(mensagem)

CAPÍTULO 07

Estruturas condicionais

Ensinando o programa a tomar decisões.

If, elseif e else

As estruturas condicionais permitem executar diferentes comandos dependendo de uma condição. 

local idade = 18

if idade >= 18 then
    print("Maior de idade")
elseif idade >= 16 then
    print("Pode votar no Brasil")
else
    print("Menor de idade")
end

A palavra if inicia a condição, elseif adiciona outra possibilidade, else define uma alternativa e end encerra a estrutura.

CAPÍTULO 08

Laços de repetição

Execute instruções várias vezes automaticamente.

While

Repete os comandos enquanto a condição for verdadeira.

local numero = 1

while numero <= 5 do
    print(numero)
    numero = numero + 1
end

Repeat Until

Executa os comandos pelo menos uma vez e repete até que a condição seja verdadeira.

local numero = 1

repeat
    print(numero)
    numero = numero + 1
until numero > 5

For numérico

Utilizado quando sabemos quantas vezes queremos repetir uma ação.

for i = 1, 5 do
    print("Estrela número " .. i)
end

For genérico

Percorre os elementos de uma tabela usando iteradores.

local planetas = {
    "Terra",
    "Marte",
    "Júpiter"
}

for indice, planeta in ipairs(planetas) do
    print(indice, planeta)
end
CAPÍTULO 09

Funções

Organizando e reutilizando blocos de código.

Criando uma função

Uma função é um conjunto de instruções que pode ser executado sempre que for chamado. 

local function saudacao()
    print("Bem-vindo ao universo Lua!")
end

saudacao()

Parâmetros e retorno

As funções podem receber informações e devolver resultados.

local function somar(a, b)
    return a + b
end

local resultado = somar(10, 20)

print(resultado)
CAPÍTULO 10

As tabelas

Uma das estruturas mais importantes de Lua.

O que são tabelas?

Tabelas são estruturas capazes de armazenar diversos valores. Elas podem funcionar como listas, dicionários e estruturas de objetos. 

local frutas = {
    "Maçã",
    "Banana",
    "Uva"
}

print(frutas[1]) -- Maçã
print(frutas[2]) -- Banana

Em Lua, os índices de uma lista normalmente começam em 1.

Tabelas com chaves

local pessoa = {
    nome = "Ana",
    idade = 25,
    cidade = "Rio de Janeiro"
}

print(pessoa.nome)
print(pessoa.idade)

Adicionando informações

local planetas = {"Terra", "Marte"}

table.insert(planetas, "Júpiter")

print(planetas[3])
CAPÍTULO 11

Módulos e bibliotecas

Organizando códigos em diferentes arquivos.

O que são módulos?

Módulos permitem separar funcionalidades em arquivos diferentes, facilitando a organização e reutilização de código.

Exemplo: crie um arquivo chamado matematica.lua.

local M = {}

function M.dobro(numero)
    return numero * 2
end

return M

Agora crie outro arquivo chamado main.lua.

local matematica = require("matematica")

print(matematica.dobro(5))
RESULTADO 10

Seu primeiro projeto

Juntando os conhecimentos em um programa simples.

🌟 Desafio: Calculadora cósmica

Vamos criar uma calculadora que recebe dois números e realiza uma operação matemática. 

print("=== CALCULADORA LUA ===")

print("Digite o primeiro número:")
local numero1 = tonumber(io.read())

print("Digite o segundo número:")
local numero2 = tonumber(io.read())

print("Escolha a operação: +, -, * ou /")
local operacao = io.read()

if operacao == "+" then
    print("Resultado:", numero1 + numero2)

elseif operacao == "-" then
    print("Resultado:", numero1 - numero2)

elseif operacao == "*" then
    print("Resultado:", numero1 * numero2)

elseif operacao == "/" then
    if numero2 ~= 0 then
        print("Resultado:", numero1 / numero2)
    else
        print("Erro: divisão por zero!")
    end

else
    print("Operação inválida!")
end
🚀

Esse projeto utiliza variáveis, entrada de dados, conversão de tipos, operadores e estruturas condicionais.
